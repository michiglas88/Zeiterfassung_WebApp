Der Import fügt Einträge aus der Datei zu deinen aktuellen Daten hinzu (bereits vorhandene Einträge werden nicht doppelt angelegt). Bestehende Daten werden dabei nicht gelöscht.

Automatische Sicherung über GitHub

Speichert deine Daten als Datei in deinem GitHub-Repo — dadurch bleiben sie erhalten, auch wenn du Browser oder Gerät wechselst oder Browserdaten löschst.

So richtest du das ein: Erstelle auf GitHub unter Settings → Developer settings → Personal access tokens → Fine-grained tokens einen Token, der nur für dieses eine Repository gilt, mit der Berechtigung „Contents: Read and write". Der Token wird ausschließlich lokal in deinem Browser gespeichert und direkt an GitHub gesendet — aber im Klartext im Browser abgelegt. Nutze ihn daher nicht auf gemeinsam verwendeten Geräten, und widerrufe ihn jederzeit über GitHub, falls nötig.
Einträge werden zusätzlich lokal im Browser gespeichert (localStorage) und sofort angezeigt. Für dauerhaften, geräteübergreifenden Schutz nutze die JSON-Sicherung oder die GitHub-Sicherung im Reiter „Daten & Sicherung". Wochenbasis: Montag–Sonntag, Regelarbeitszeit 40 Std./Woche.
